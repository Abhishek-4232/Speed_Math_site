# 💜 MathForge — Master Your Mental Maths

**MathForge** is a free, interactive mathematics learning and mental calculation platform designed to help students improve calculation speed, accuracy, logical thinking and quantitative aptitude.

Whether you're preparing for RRB NTPC, SSC CGL, banking examinations or other competitive exams, MathForge provides practice tools, learning resources, mock tests and brain-training games in one place.

> Learn smarter. Calculate faster. Think better.

---

- BODMAS, squares, cubes and square roots.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js (LTS version recommended)
- npm
- Git
- Visual Studio Code (recommended)

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/MathForge.git
```

### 2. Navigate to the project

```bash
cd MathForge
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

```text
http://localhost:5173
```

*Note: These commands assume the root package.json provides the corresponding scripts. If your project uses separate frontend and backend packages, follow their individual setup instructions.*

## 🎨 Design Philosophy

MathForge focuses on three principles:

- **Simplicity:** A clean interface that keeps learners focused.
- **Engagement:** Interactive practice, challenges and progress feedback.
- **Accessibility:** Responsive layouts and comfortable colour themes.

The visual identity uses a lavender and purple colour palette.
